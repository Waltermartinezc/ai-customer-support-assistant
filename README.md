# 🤖 AI Customer Support Assistant

## 📊 Descripción
Este proyecto es un prototipo de asistente virtual basado en Python. Su objetivo es clasificar y responder automáticamente a las consultas frecuentes de los usuarios, derivando los casos complejos a agentes humanos.

## 🎯 Objetivos
- Automatizar la clasificación de tickets entrantes.
- Generar respuestas automáticas seguras y apegadas a los procedimientos de calidad.
- Reducir el tiempo de primera respuesta.

## 🛠️ Tecnologías
- Python
- OpenAI API (Simulación)
- JSON
